## Trained Models and Reproducibility

Due to the large size of the trained model files, all model weights and executable Python notebooks are hosted on Hugging Face.

**Hugging Face Repository:** (https://huggingface.co/shkelqim2026/EfficientNet)

The repository provides:

- **Trained model weights:** Checkpoints from the SD-OCT transfer learning experiments.
- **Python notebooks:** Notebooks for loading, running, and testing the trained models.
- **Model evaluation:** Code to evaluate model performance and reproduce the experiments, subject to the availability of the required datasets and dependencies.

### How to Run the Models

1. Open the Hugging Face repository linked above.
2. Download the notebooks and model weights you need.
3. Open the notebooks in Jupyter Notebook, JupyterLab, or Google Colab, as supported by the notebook.
4. Install the required dependencies and configure the dataset paths.
5. Run the notebook cells to load the trained model and perform inference or evaluation.

The GitHub repository contains the project code, while Hugging Face hosts the large model files and notebooks, figures, tables, scripts for independent use and experimentation.

**Note:** Reproducing the reported evaluation results may require access to the original dataset and the same preprocessing and evaluation settings used in the study.
